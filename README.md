# Привет, я Тимур

Учусь на 4 курсе информационной безопасности и занимаюсь backend-разработкой на Go. Здесь собираю учебные проекты: HTTP API, работу с PostgreSQL и конкурентную обработку задач.

Основной стек — **Go, PostgreSQL, Docker, Git и Linux**. Также знаком с Python и основами JavaScript. Интересуюсь базами данных, сетями и тем, как устроены операционные системы.

## Проекты

### [Team Task Manager](https://github.com/lumen-dev02/team-task-manager)

Самый большой проект в профиле — API для совместной работы над задачами, основа для курсовой. Есть пользователи, проекты, участники, исполнители и история статусов. В нём разбираю JWT, права доступа и SQL-транзакции: например, что должно произойти, если одного участника одновременно назначают на задачу и удаляют из команды.

### [Background Job Processor](https://github.com/lumen-dev02/background-job-processor)

Обработчик фоновых задач с ограниченной очередью и пулом воркеров. Через HTTP можно отправить задачу и получить её результат. Основной упор — на goroutines, channels, таймауты и корректную остановку. Все данные хранятся в памяти.

### [URL Shortener](https://github.com/lumen-dev02/url-shortener)

Небольшой сервис сокращения ссылок: генерация короткого кода, редирект и счётчик переходов. Go, стандартный `net/http` и PostgreSQL.

### [Task Tracker API](https://github.com/lumen-dev02/task-tracker-api)

API для личных задач с регистрацией и JWT. Каждый пользователь видит и меняет только свои записи; есть статусы, фильтр и пагинация. В отличие от командного менеджера, здесь нет проектов и ролей — упор на обычный REST API и проверку владельца в SQL. Интеграционные тесты проверяют в том числе попытки получить доступ к чужим задачам.

В каждом репозитории есть инструкция запуска и тесты. Более подробные решения и ограничения описаны рядом с кодом.
